# 验收规则

构建、离线测试和文件校验不能代替当前网页、账号或正文验收。

## 页面判定

只有目标正文实际出现时才算 captured。搜索壳、登录页、推荐页、平台介绍和视频简介不能代替目标内容。

不要仅凭 URL 中的 login、signin、passport、404 或 error 判定受限。结合正文长度、可见密码框、登录弹窗、可见 video 和目标内容判断。可关闭的登录弹窗先尝试关闭；仍无法读取时保存 awaiting_user。

直接图片 URL 以图片文件为证据，不要求登录。公开视频页只要 video 正在显示，就按可见视频处理。

## 读取顺序

1. 独立无头 Edge。
2. 已连接 Edge 的最小化补读。
3. 用户手动登录或验证后 continue。

需要在可见浏览器直接打开目标页时，使用 `live open URL --headed --out TASK` 后检查当前页面。

补读结果按“正文已确认、状态、内容量”选择更好的结果。明确拒绝访问、robots 禁止、限流、取消和预算耗尽均停止自动换入口补读。

## 结果含义

状态含义见 [evidence.md](evidence.md)。详情和媒体分别验收；截图、HTTP 200、链接存活和扩展连通不能互相替代。

## 检索性能

比较同一组查询时固定站点、候选、正文、截图设置与浏览器配置。记录整批耗时、服务端观察到的同时请求数、逐站峰值、归档字节、进程树峰值和回执 token。指定分词器并分别计量回执与完整索引。用预先标注的正文校验选中网址与页面实文，加入拼写干扰、延迟换文和单站限流样例。

`LUZ_HEADLESS_INTEGRATION=1` 时，`tests/search-archive.test.mjs` 会用真实 Edge 核验单条查询、跨站正文并发、标签页关闭和单条紧凑回执。
