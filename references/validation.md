# 验收规则

构建、离线测试和文件校验不能代替当前网页、账号或正文验收。

## 页面判定

只有目标正文实际出现时才算 captured。搜索壳、登录页、推荐页、平台介绍和视频简介不能代替目标内容。

不要仅凭 URL 中的 login、signin、passport、404 或 error 判定受限。结合正文长度、可见密码框、登录弹窗、可见 video 和目标内容判断。可关闭的登录弹窗先尝试关闭；仍无法读取时保存 awaiting_user。

直接图片 URL 以图片文件为证据，不要求登录。公开视频页只要 video 正在显示，就按可见视频处理。

## 读取顺序

1. 独立无头 Edge。
2. 已连接 Edge 的最小化补读。
3. 用户手动登录或验证后 continue。

补读结果按“正文已确认、状态、内容量”选择更好的结果。限流、取消、预算耗尽不触发换入口重试。

## 结果含义

- captured：正文在声明范围内稳定可读。
- partial：有正文但仍有展开、分页、媒体或预算缺项。
- awaiting_user：等待用户操作。
- blocked：限流、权限、安全策略或目标缺失。
- failed：浏览器或归档执行失败。

详情和媒体分别验收；截图、HTTP 200、链接存活和扩展连通不能互相替代。
