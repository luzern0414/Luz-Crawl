# 验收边界

构建、文件完整性和离线测试只证明分发产物具备相应条件，不能代替当前网站、账号登录或完整采集验收。

平台说明中的公开样本记录来自历史验证。网站可能更新，同一站点的页面、搜索、详情、统计与媒体需要分别检查；可扩展网站库也包含尚未验证的候选和失败记录。

每次实际采集均以浏览器取得的目标内容为准：搜索外壳不算正文，视频简介不算完整视频，当前加载的评论不算全部评论。遇到登录、验证、限流或预算耗尽，保留真实状态并按 Skill 规则接续或停止。

verify 验证本地文件与记录的 SHA-256 是否一致，不证明来源真实性、网站当前可用性或下载权限。完整字段要求见[证据规范](evidence.md)。

## 登录与 404 判定（2026-10-28 修正）

页面级判定按下列规则执行；只有确实读不到目标正文时才判 `login_required` / `unavailable`。历史记录里被旧规则误判的页面，重新 capture 即可，不必让用户登录。

| 规则 | 判为登录 / 404 | 不判（旧规则误判的例子） |
| :--- | :--- | :--- |
| 网址含 login / signin / passport | 仅当它是路径最后一段（`/login`、`/user/signin.html`），或路径以 `/passport/` 开头，或 hash 为 `#/login` | 路径中间出现：`developers.weixin.qq.com/.../open-api/login/wx.checkSession.html` |
| 可关闭的登录弹窗 | 弹窗含“登录 / sign in”，且未定位到超过 500 字的目标正文、页面上也没有显示中的视频 | 抖音视频页匿名访问弹出的登录框（视频照常播放） |
| 页面有可见密码框 | 同时没有 `article`，且正文不足 3000 字 | 组件文档里的密码框演示：`element-plus.org/zh-CN/component/input.html`（正文 5000+ 字） |
| 网址含 404 / notfound / error | 仅当它是路径最后一段，且正文不足 1500 字 | 文档路径如 `/docs/error/handling` |

仍需人工处理的真实情况：知乎搜索页（匿名只返回约 470 字的登录外壳）、1688 / 知乎专栏 / 花瓣的安全验证、小红书搜索。GitHub 等专用采集逻辑的平台不经过这套页面级判定，直接打开它们的登录页也会被记为 captured，这是原有行为。
