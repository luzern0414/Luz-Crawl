# 合规与采集边界

本页是采集前的核对表，不是法律意见。条文与平台条款以发布方当前版本为准；下表为 2026-11-02 实际读取的内容。

## 采集前核对

| 步骤 | 做法 | 依据 |
|---|---|---|
| 1 范围 | 只读公开页面，条数少、用途明确（调研、核对、引用），由用户指令触发；不做全站或持续采集 | 个人信息保护法第六条；数据安全法第三十二条 |
| 2 爬虫规则 | 批量或重复读取同一站点前运行 `robots URL`；禁止或无法读取时不批量，由用户决定并写入未覆盖范围 | [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html) |
| 3 站点条款 | 读目标平台的用户协议、使用政策；条款禁止自动化读取时，只做用户明确要求的单页读取并如实告知 | 下表“平台” |
| 4 个人信息 | 只保留回答问题所需的字段；评论、昵称、主页属于个人信息 | 个人信息保护法第四、六、二十七条 |
| 5 版权 | 下载的图片、视频、文章只作调研依据；引用须指明作者与作品名称，不重新发布、不商用 | 著作权法第二十四条 |
| 6 节奏 | 沿用 `policy` 的平台窗口；收到 429 或限流页即停止该站，不换入口规避 | [GitHub 限频说明](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api) |

`robots` 只请求站点根目录的 `/robots.txt`，不读页面，不计入 sources。输出 `outcome`：`allowed`、`disallowed`、`unavailable`（4xx，规则允许访问）、`unreachable`（5xx 或失败，按 RFC 视为全部禁止）；退出码 2 表示不允许。RFC 9309 第一节明确这些规则不是访问授权：允许不等于站点同意，禁止也不等于违法，只是批量读取的停止信号。

## 平台

| 平台 | 已读依据 | 对本技能的约束 |
|---|---|---|
| 小红书 | robots.txt 对 `User-agent: *` 为 `Disallow: /`，仅少数搜索引擎有放行路径；用户协议原文未能取得 | 只做用户指定的少量公开笔记；不批量、不转售；协议未核对，使用前由用户确认 |
| 抖音 | [用户服务协议](https://www.douyin.com/agreement) 第 2.4、5.1、5.3(4) 条禁止爬虫、使用自动化程序收集内容、模拟下载，第 5.3(7) 条禁止将内容用于任何销售和商业使用；robots.txt 没有对通用爬虫的全站禁止 | 同上；下载的视频只作调研依据，不用于传播或商用 |
| GitHub | [robots.txt](https://github.com/robots.txt) 对通用爬虫禁止 `/search$` 和带 `?q=` 的页面，并说明抓取请联系 GitHub、数据可用官方 API；[使用政策](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies) 把机器人抓取称为 scraping，不含 API，禁止用采集到的个人信息发垃圾信息或出售；[服务条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service) 第 D.8 条说明条款不限制第三方合法访问公开仓库 | 浏览器搜索只用于少量候选发现；批量或持续检索改用官方 API（认证后搜索接口每分钟 30 次，未认证 10 次）；不收集用户邮箱、不做招聘或营销名单 |
| 其他网站 | 以各自 robots.txt 和条款为准 | 先 `robots`，再决定是否读取 |

## 法律依据

| 法律 | 条文 | 对采集的含义 |
|---|---|---|
| 个人信息保护法（2021-11-01 施行） | 第四条定义个人信息与处理（含收集、存储、使用、公开）；第六条收集限于最小范围；第十三条第六项、第二十七条可在合理范围内处理已公开的个人信息，个人明确拒绝的除外，对个人权益有重大影响的须取得同意 | 公开不等于可随意使用：不建画像、不聚合到个人、不重新公开、不用于触达；发现拒绝表示或敏感信息（第二十八条）即删除 |
| 数据安全法（2021-09-01 施行） | 第三条数据处理含收集；第三十二条收集数据应采取合法、正当的方式，不得窃取或以其他非法方式获取 | 不破解验证码、不绕过权限、不用未授权接口 |
| 网络安全法（2025-10-28 修正） | 第二十九条任何个人和组织不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等活动；第四十三条网络运营者收集个人信息应合法、正当、必要 | 同上；速率受控，不干扰站点运行 |
| 著作权法（2020 修正） | 第二十四条：为个人学习、研究，或为介绍、评论而适当引用已发表作品，可不经许可，但应指明作者姓名和作品名称，且不得影响正常使用、不得不合理损害权利人利益 | 引用只摘取必要片段并标明来源；整篇转载、商用须另行授权 |
| 美国版权法第 107 条（境外来源） | 合理使用看使用目的与性质（含是否商业）、作品性质、使用的数量与实质性、对潜在市场的影响 | 同上，逐案判断，不以“公开”替代判断 |

## 浏览器与会话

- 静默 Edge 的 `_browser-profile\edge*`（输出根下，默认 `E:\Skill输出\Luz-Crawl\_browser-profile\`）保存登录状态，等同 Playwright 文档所说的认证状态文件：可能含能冒充账号的 Cookie 和请求头，不进仓库、不外发（[Playwright 认证](https://playwright.dev/docs/auth)）。
- 本技能不做代理轮换和会话池：[Crawlee](https://crawlee.dev/docs/guides/session-management) 的会话池用于轮换代理 IP 与 Cookie 以避免被封，这与“限流即停止、不规避”的规则相反，不采用。
- 浏览器自动化信号：`lib/bridge/stealth.mjs` 能隐藏 `navigator.webdriver` 等标志。这会让网站无法识别自动化访问，与上面“不规避”的原则有张力，也让抖音协议第 5.1 条这类限制更难被站点执行。因此默认不注入，浏览器的自动化标志保持可见；只有用户明确授权的一次运行才设置环境变量 `LUZ_STEALTH=1` 打开。
