# 先规划，再逐站实测

## 建池与扩展

先写目标、地区/语言、时间范围、所需字段、关键词组和有用结果标准，再准备网站池。获客可按采购公告/意向、总包分包、开发商、企业资质、装企/经销商、协会展会、B2B/外贸、内容获客和设计物料拆分；不要只搜产品词或只找同行。

从 [site-library.json](site-library.json) 选相关入口，再从原站友情链接、产品导航、公告原始来源、展商名单和报告引用发现新站。库只是起点，不能反复固定使用同一小名单。候选先加入唯一任务目录的 platform-plan.json；记录 id、name、url、kind、purpose、queries、discovered_from、账号要求和状态。按规范 URL 去重，但保留同一平台业务不同的入口。候选地址也可能失效，不能标为已验证。

覆盖要与问题对应：政府采购/公共资源/国企与总包采购；企业/工程/装企/行业名录；电商数据/官方创作者/商家/广告/联盟；趋势与研究报告；设计灵感/建筑/品牌/UI/素材。用户明确要求大量补充与逐站试用时，对计划内每个入口留实测或具体阻塞记录，不能只扩池。

## 逐站验收与有界并发

独立站点用 `batch --file jobs.json --out TASK_FOLDER` 同时执行（默认 4 条、最多 6 条队列，`--concurrency 1–6`）。URL 列表适合试入口，`{id,url,steps}` 适合已观察过控件的站内查询；同一站点队列与每页步骤保持串行。禁止把有顺序依赖的“先查列表、再选详情”当成独立任务并发；先核对列表，再生成详情计划。登录/验证/限流时停放该站，继续无关站点；不要为同站另开批次绕过队列。[参数与返回语义](browser-api.md#多站并发)。

1. 打开原站，read / locate 看可见控件与落地地址，等待目标元素加载。页面文本短、href 少或只有第一张 article 卡片不代表无数据；JS 路由和 onclick 列表需实际点击。
2. 定位唯一可见输入框，填用户原词，点击搜索/查询，核验输入值、结果页标题/地址与结果内容。记录筛选、排序、日期、分页和零结果。失败先根据新 DOM 修正，不猜参数反复请求。同步新开页由click转入同一任务页；仍须核实真实落地地址。
3. 有结果后选相关卡片进入详情，读标题、来源、日期、目标正文和可见字段。搜索结果、推荐卡片、产品介绍与详情分开保存。无 href 的卡片使用页面实际控件，不能编 URL。
4. 数据站先进入榜单、类目或分析产品，核对时间窗口、地区、账号角色、指标定义与原始单位；公开趋势、估算 GMV、热度、样例和自有账号数据分开。设计站核验作品详情、作者、图片与来源；图片下载另验，不默认获得商用权。
5. 登录、会员、验证码与冷却按 browser-api.md 停放并记录，可继续其他无关站点。网络失败不能标成必须登录，操作 completed 不能标成数据已取得。不要重复访问已经要求验证码的入口。

政务与采购站常见的坑：结果标题可能是含高亮子节点的 span，不能只取 a 链接，侧栏“热门搜索”不是本次结果；详情可能先出日期再异步加载表格，或把正文放在 iframe 里，用 wait_for 等正文标志、读真实 iframe.src 后再打开，不猜地址；全站搜索 0 条时改走原站分类列表的查询控件，不能当作站内无内容；详情只有字段标签、值为空时记 partial。具体选择器与样本见网站库 gdggzy、gd-zfcg、ggzy 条目的 notes，复用前仍观察当前 DOM。

用户要求原站搜索时不转 Bing/Google。search web --site 是外部索引；未知站用 search 域名 或 browser 原站表单。确实没有通用表单时用原站分类/榜单/目录，并如实标注 search 未验证。未登记站点只在用户允许时用搜索引擎发现候选（已登记社交与技术平台的自动公开索引见 SKILL.md“搜索与采集”）；索引结果不能作为正文或统计证据。

## 验收与积累

每站分别记录 page、search、detail、statistics、media，状态为 verified / partial / blocked / failed / untested，附采集时间、证据相对路径、实际 URL、控件、结果范围与限制。首页能打开不等于可搜索；一次样本不代表全站或所有账号永久可用。

网站库中的 `probe` 仅保存历史派发状态，`probe.status=completed` 不会自动提升任何 `verification`。`route` 是当次观察到的控件与地址样本，执行前仍需定位确认；0条结果须保留查询、地区、时间与分类，不能据此断言全站无相关信息。该库不携带本机证据路径，完整原始证据留在任务目录。

统计字段保留 metric、raw_value、unit、period、region、filters、source_url、captured_at 和 definition。隐藏数值留空，万/区间/估算不伪造精确值；热度不等于成交额，平台营销数字不等于本次类目统计。项目保留公告类型、发布日期、截止日期和客户角色；历史中标仅作为潜在采购方线索。

raw 内保留原始浏览器证据，成品报告与实测表放 raw 同级；自动采集记录 `TASK_FOLDER/raw/爬取总结.html` 是例外。统计访问过、搜索验过、详情验过、数据验过、阻塞、失败与未测数量，不用一个成功率覆盖不同能力。

任务结束把可复用公开入口、发现来源、真实控件、验证范围和失败修正写回 site-library.json；只带便携经验，不带本机路径、账号、cookie、token、登录任务和私人后台数据。未经验证的入口保留 candidate/untested；只有证实正确的域名、站内模板或交互路线才进入 opencli/catalog.json。任务原始证据仍留在任务目录。
