LuzCrawl

用真实浏览器搜索、采集并保存网页证据。

安装

  1. 安装 Node.js 24.5+ 和 Microsoft Edge。
  2. 在 Edge 扩展管理页打开开发者模式，加载技能目录中的 browser-extension/。
  3. 在技能目录运行：
node scripts/luz-crawl.mjs install
node scripts/luz-crawl.mjs doctor

ready: true 且扩展已加载后即可使用。更新扩展后重新加载。

使用

node scripts/luz-crawl.mjs doctor
$task = (node scripts/luz-crawl.mjs begin "主题" --out "D:\输出" --new | ConvertFrom-Json).folder
node scripts/luz-crawl.mjs experience --query "关键词"
node scripts/luz-crawl.mjs search github "browser automation" --read 0 --out $task
node scripts/luz-crawl.mjs capture "https://example.com/article" --out $task

每项需求使用一个输出目录。搜索结果是候选；打开详情确认正文后才算有效来源。

常用命令

  • search：搜索网站或开源项目。
  • capture：读取一个网页。
  • collect：按主题搜索并汇总。
  • batch：批量执行 URL 或搜索任务。
  • download：补下载已观察到的媒体。
  • pending / continue：处理登录或验证任务。

任务状态

captured 已读取正文；partial 有内容但不完整；awaiting_user 等待登录或验证；blocked 被站点限制；failed 执行失败。

边界

不破解验证码、不绕过付费或权限、不导出 Cookie。只保存当前浏览器实际看到且用户有权访问的内容。点击、输入、提交等写操作必须有明确授权并使用 --allow-write。
